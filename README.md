# Expense Tracker - Full Stack
   
   Full-stack expense tracking application with ASP.NET Core backend and React frontend.
   
   ## Structure
   - `/backend` - ASP.NET Core API
   - `/frontend` - React application
   
   ## Running Locally
   
   ### Backend
```bash
   cd backend
   dotnet run
```
   
   ### Frontend
```bash
   cd frontend
   npm install
   npm run dev
```
